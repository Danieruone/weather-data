# Track the temperature of your room

you will need: 

- Node MCU ESP8266
- Temperature & humidity sensor

### Setup your environment

Create your arduino file with the ESP8266 and load the C code. Make sure you have the wifi and port in the correct way. 
After this you can run the node server and see the static html route!

- Install dependencies
 ```
$ npm install
 ```

- Run project
 ```
$ npm run dev
 ```
